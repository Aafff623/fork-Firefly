文旅海报一旦写成「风景好看、人物开心」，模型只会给你一张正确但没记忆点的插画。

这套模板把风格钉死在**扁平矢量海报**：粗黑轮廓、圆角几何、纯色块、极简五官、彩带涂鸦、干净留白、竖版 4:5。你只管填五个槽——人、动物、姿势、服装、风景——外加一块调色板。填完直接贴进 GPT 出图。

原料是一篇微信短文 + 三张效果图；关注引流已删，只留模板和例证。出处链接原文未附，见文末脚注。[^1]

## 完整提示词（逐字可复制）

占位符保留方括号，用中文具体名词替换后再提交。

```text
一张趣味十足的扁平矢量海报插画，描绘了[人类]与[动物]以[姿势]摆出各种姿势，身着[服装]，置身于[风景]之中。使用干净利落的粗黑轮廓线、简洁的圆角几何图形、扁平的纯色填充、极简的面部细节、小巧的中性眼神、平静的表情、简化的手部和身体比例、柔和的色块、零星的彩带涂鸦、小巧的抽象图标、干净的留白、清晰的图形海报布局以及精心控制的[调色板]。竖版 4:5 构图。
```

### 槽怎么填

| 占位符 | 填什么 | 例（对照上图） |
|---|---|---|
| `[人类]` | 人数、年龄、关系 | 一对穿民族服饰的孩童 / 一名女孩 / 四个孩子 |
| `[动物]` | 品种 + 是否拟人配饰 | 云南瓦猫 / 戴围巾的花猫 / 熊·长颈鹿·企鹅等 |
| `[姿势]` | 动态或队形 | 跳跃举手 / 路牌前合影式挥手 / 草地排排坐挥手 |
| `[服装]` | 地域或季节特征 | 绣花马甲与条纹裙 / 蓝绣花白裙 / 背带裤与针织帽 |
| `[风景]` | 地标 + 前景物 | 红河梯田与石桥 / 大理门楼与雪山路牌 / 草地丘陵彩旗 |
| `[调色板]` | 主色 3–5 个，写死 | 红橙绿梯田色 / 天蓝金黄民族蓝 / 黄绿橙米色 |

风格句已经很长，**别再往模板里塞「高级、震撼、电影感」**——那些词会冲掉扁平矢量约束。要改气质，动槽位和调色板就够。

下期风格征集原文提到：国风 / 赛博朋克 / 日漫 / 写实人像 / 美食 / 建筑——需要哪条再单独开篇，别和这篇扁平文旅槽硬揉。
