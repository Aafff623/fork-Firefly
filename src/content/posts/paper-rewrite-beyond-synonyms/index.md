换同义词、拆长句，查重还是红一片——因为动的是词，骨架没动。更糟的是为「看起来不一样」去改变量、数据或结论边界：那不是降重，是改研究结果。

稳一点的做法：先锁事实，再看重复到底是短语、句式，还是同一观点反复念，然后动句式、信息顺序和段落功能。一次改 1～3 段，改完立刻对术语和引用。

下面 10 个 Skill 覆盖局部改写到全文回检。适合改自己的稿，或在规范引用下重整合文献；不是整篇丢给 Agent 一句「帮我降重」。

## 换词为啥总救不了查重

| 表面动作 | 实际没动到的东西 |
|---|---|
| 因此→所以、研究表明→结果显示 | 主谓关系、从句嵌套、论证路径 |
| 长句硬拆 | 信息仍按原稿顺序排队 |
| 强行「差异化」 | 变量名、系数、显著性、结论范围被改歪 |

查重标红 ≠ 立刻开换。先诊断，再选刀。

## 别一锅炖：先锁事实再动刀

```text
锁定事实 → 诊断重复 → 句法重构 → 信息重组
→ 段落功能 → 文献综合 → 引用核查 → 全文回检
```

章节力度别一刀切：

- **方法 / 结果**：求稳。术语、样本、模型、数值能不动就不动；目标是准确可复现，不是「改得越不像越好」。
- **引言 / 理论 / 综述**：句式和信息组织可以动得狠一点，但仍禁止加原文没有的事实。

降重降的是表达重复，不是研究内容；改写法，不改结论。查重率下降也不是唯一成功标准。

## 10 个 Skill 一张表

| # | Skill | 干什么 | 优先章节 |
|---|---|---|---|
| 01 | 术语与事实锁定 | 先列不可改清单，再动笔 | 方法、结果、假设 |
| 02 | 重复表达诊断 | 分清信息重复 / 句式重复 / 观点复读 | 连续标红、啰嗦段 |
| 03 | 句法重构 | 重排主谓、从句、信息重点；出简洁/学术两版 | 长句、理论分析 |
| 04 | 信息顺序重组 | 拆信息单元，按「问题→认识→不足→切入」重排 | 背景、引言、现状 |
| 05 | 段落功能重写 | 观点→证据→解释→回扣问题 | 散段、衔接生硬 |
| 06 | 多文献主题综合 | 共识→分歧→不足，禁作者流水账 | 综述、理论基础 |
| 07 | 方法段精准改写 | 保样本/变量/模型/流程；禁空增步骤与软件 | 数据、模型、实验 |
| 08 | 结果段数据驱动 | 少模板话，直接写系数/显著性/组间差异 | 回归、稳健性、实验 |
| 09 | 引用边界核查 | 防相关变因果、范围扩大、措辞过强 | 综述、讨论 |
| 10 | 全文一致性回检 | 术语统一、数据未漂、假设↔结果、风格突变 | 交稿前 |

## 粘贴即用的提示词骨架

共性约束（建议写进每条 system / 开头）：不改术语、数据、公式、引用编号；不新增原文没有的事实、方法、软件版本；不把相关写成因果。

### 01 术语与事实锁定

暂不改写。输出：①不可修改；②可调表达；③须特别注意的事实。原文：【段落】

### 02 重复表达诊断

暂不改写。判断：可删并的信息重复、重复句式、可重组观点、必须保留的术语数据引用；最后给改写顺序。原文：【段落】

### 03 句法重构

禁逐词同义替换、禁只调语序。重排主谓、主从、信息重点、句间衔接。给 A 简洁自然 / B 偏学术两版。原文：【段落】

### 04 信息顺序重组

拆信息单元并说明作用；按「核心问题→已有认识→现有不足→本文切入点」重排；不加新事实。原文：【段落】

### 05 段落功能重写

不沿用原句序。按：核心观点 → 证据 → 解释 → 与本文问题的联系。删重复，保留引用与事实。原文：【段落】

### 06 多文献主题综合

按共识→分歧→不足主题化；勿按作者流水账。保留引用编号且不错配；每结论标注支持文献；冲突写明，禁止硬合并。材料：【观点+编号】

### 07 方法段精准改写

必须保留：对象、样本量、时间范围、变量定义、模型名、参数、操作顺序。可删重复、合并步骤、调句式。禁增新流程/检验/软件/数据处理。改完单列「保留事实」供核对。原文：【方法段】

### 08 结果段数据驱动

少写「结果表明 / 研究发现 / 进一步说明」。优先：系数方向、显著性、组间差异、与假设对应。数值与统计结论不动；相关不升格为因果；不加原文没有的解释。原文：【结果段】

### 09 引用边界核查

对照改写稿与原始摘要 / 原文 / 读书笔记。查：相关→因果、对象/范围扩大、「必然 / 完全 / 始终」过强、引用是否撑得住、超出结论的推断。有风险给更谨慎表述。缺证据材料时 Agent 只能猜文风，不能猜文献证明了什么。

### 10 全文一致性回检

本轮不大幅润色，只找问题：术语前后一致；数据 / 公式 / 引用编号未漂；假设与结果对应；论断强度未超原稿；机械化表达；章节风格突变；遗漏 / 重复 / 逻辑断裂。输出问题清单（章节 / 原稿 / 改写稿 / 问题 / 建议改法）。

## 自己动手时记着这几条

- 一次 1～3 段，改完立刻对清单，别攒几十页再对。
- Agent 空增检验方法、软件版本、没做过的数据处理——直接删，别因为「像论文」留下。
- 没给原始文献或读书笔记，就别指望「引用边界核查」真能核边界。
- 方法段目标不是差异最大化，是可复现；结果段能说清系数和显著性，就别连着换三种「表明」句式。

## 整篇扔给 AI，差在哪

整篇一句「帮我降重」：难控事实漂移，容易掉进换词循环。  
拆开这条线：每步有明确输入输出，章节力度不同，最后用全文回检确认「还是原来那篇研究」。

原文还带学术 skills 导流包；本帖只收可复用的改写工序与提示词骨架。
