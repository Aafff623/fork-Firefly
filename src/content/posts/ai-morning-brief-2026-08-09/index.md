## Tibo 把付费额度冲了，还说明一再冲

这是负责人手动开闸，不是套餐条款改了。别把「Tibo 心情好」写进自己的月预算。

原题：[Codex 重置全部付费用户用量限制，周一将再次重置](https://x.com/thsottiaux/status/2086188036493344823)。Tibo 宣布重置 ChatGPT Work 和 Codex 全部付费用户的用量。有人说这是表演，因为周额度刚刷新。他回：当地时间周一再来一次。周一那次后来在 11 日早报里对上了。

两次连冲说明需求侧压力大，不说明下周还有。额度怎么耗，还是看 [Codex 手册](/posts/codex-handbook/)。个人仓把「等重置」当产能规划，会在闸门关上的那天卡死。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-09/)。

## Claude Code 里跑别的模型，Boris 说不是封号理由

能接 ≠ 能跑好。Boris 说的是风控误伤，不是发了一份迁移说明书。

同一条推文链里，有人按 Tibo 以前的办法把 OpenAI 模型接到 Claude Code，Anthropic 账号被停。Tibo 转发问：只换壳就封，奇怪。[Boris Cherny 下场](https://x.com/thsottiaux/status/2086188036493344823)：不会因为你在 Claude Code 里用其他模型就封；更像风控分类器误伤，团队在查。他也说了，Claude Code 本来就能经 LiteLLM 一类工具接别的模型，只是工具和提示词不是换个名字就能通用。

我这边 [把 Claude 的规矩搬去 Cursor](/posts/cursor-claude-harness-migration/) 踩过：路径、Skill、Windows 编码，复制过去经常是半残。Tibo 后来那句「harness 该让用户自己选模型」，是立场，不是迁移说明书。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-09/)。
