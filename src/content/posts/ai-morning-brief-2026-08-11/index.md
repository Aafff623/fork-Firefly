## Sonnet 5 那档 2 / 10，不用等到 8 月底涨回去

这改的是 API 刊例，不是 Claude Code 订阅积分。Pro / Max 包月还是包月。

原题：[Claude Sonnet 5 定价永久保持2美元/10美元每百万token](https://x.com/claudeai/status/2086891169217122586)。官方账号说：每百万 tokens 输入 2 美元、输出 10 美元，原定 8 月 31 日结束的优惠价，转正了。

API 走 Sonnet 5 的人，8 月底不用再留一笔「涨回去」的预算。Claude Code 里的用量仍按订阅档的五小时 / 周额度走，别把 $2 / $10 直接乘进 Pro 账单。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-11/)。

## 千问多模态插件，能挂进 Claude Code 和 Codex

这是工具链，不是百炼 Token Plan 改价。装上不等于免费视觉。

原题：[Qwen 官方发布 Qwen-MM-Plugins 多模态插件](https://github.com/QwenLM/Qwen-MM-Plugins)。GitHub 上这套插件按 skill + 可选 MCP 拆，官方写了能在 Claude Code、Codex 里装。读图读视频可以不配 Key；OCR、grounding、生成类要 `DASHSCOPE_API_KEY`。

Key 配错会按量走百炼，那是另一张账单，跟 Coding Plan 白名单不是一回事。Skill / MCP 怎么写，还是 [Agent Skills 手册](/posts/agent-skills-handbook/) 和 [MCP 手册](/posts/mcp-handbook/)。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-11/)。

## ChatGPT Business 要卖五倍用量的贵席位

个人 Codex 订阅不是这条。公司仓如果经常撞五小时墙，这是明确的加钱档，不是又一次 Tibo 手动重置。

原题：[OpenAI 即将为 ChatGPT Business 订阅推出五倍用量的高级席位](https://openai.com/index/premium-seats-chatgpt-business/)。官方：高级席位用量是标准席的 5 倍，取消五小时限制，改成可预期的周重置。标价每用户每月 125 美元，年付折合每月 100 美元。标准席仍是 25 / 年付 20。同一工作区可以混配。限时还有：前 1 万名符合条件的 workspace，每加一个 Premium 席送 100 美元积分（最多 5 席 / 500 美元），报名窗口写到 8 月 20 日。

个人 Plus / Pro / Codex 别拿这张价目表对。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-11/)。

## OpenRouter 的自动路由，改跟市场花钱的方向走

省钱的前提是你接受「今天和昨天可能不是同一个模型」。写代码要可复现，别把生产 Agent 默认扔给 auto。

原题：[OpenRouter Auto Router 升级，按实际消费份额路由模型](https://openrouter.ai/openrouter/auto)。新路由按近 7 天匿名支出份额和任务类型选模型，市场迁走它几天内会跟。调用还是 `openrouter/auto`，可加成本档和允许列表，不另收费。

要锁，就写死模型名。调试日志里如果只看到 auto，出了幻觉你都不知道该找哪家供应商。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-11/)。

## Muse Glimmer 权重开了，Spark 1.2 还在预告

能下权重 ≠ Cursor 池子里能选。跟现用的 Claude / GLM / Kimi 不是一条产品线。

原题：[Meta 发布 Muse Glimmer 并预告 Muse Spark 1.2 开源权重](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)。约 30B 的 Agentic 模型，Apache 2.0，[Hugging Face](https://huggingface.co/meta-models/Muse-Glimmer-30B) 可下。官方往本地常驻 Agent 推：单卡消费级 GPU / Mac 能跑，量化后大约塞进 24–32GB 显存信封。llama.cpp / MLX / ExecuTorch 的优化集成当时还写「未来几天」。

想试长 Agent 执行层可以玩；别为了它改明天的付费模型。来自[橘鸦早报](https://daily.juya.uk/issues/2026-08-11/)。
