# Cloudflare 能提供什么 · 对本站的对照（含「大善人」）

> **状态**：知识备忘 · Phase CF 决策用  
> **日期**：2026-08-12  
> **诉求**：自定义域名（已有）+ EdgeOne 国内向加速（已有）+ CF 图床/防攻击等服务（待做）

## 「Cloudflare 大善人」是什么意思

中文圈口头禅，大致指：

- 免费档就能用全球 DNS / CDN / HTTPS / 基础防护  
- **R2 出站流量免费**（对比 AWS S3 按流量收钱，这点最「善人」）  
- Workers / Pages 有慷慨免费额度，个人站经常 $0  

**但不是无限公益：**

| 传说 | 实际 |
|---|---|
| 免费 CDN 无限刷大文件/视频 | 官网边界：别拿标准 CDN 当网盘/视频站；滥用会限速或要求升档 |
| 免费 = 大陆加速 | **不对**。CF 免费层对大陆覆盖弱；国内打开靠 **EdgeOne**，不是靠 CF |
| 注册即全站防攻击 | 流量必须 **橙云代理** 才吃到 WAF/DDoS；主站若只走 EdgeOne，CF 护不到页面 |
| 什么都免费永久 | R2/Workers 等有月/日限额；超了要付费或失败 |

对本站结论：**「大善人」主要体现在 R2 免出站 + 免费防护/DNS 壳；国内加速别指望 CF。**  
优化落地见 [`architecture-cost-optimized.md`](./architecture-cost-optimized.md)。

## 产品清单 → 本站用不用

### A. 几乎人人说的「免费壳」（网站计划 Free）

| 能力 | 做什么 | 对本站 | 备注 |
|---|---|---|---|
| **DNS** | 托管解析 | 可选 | 现 Name.com 也能管；迁 NS 为用橙云/统一面板 |
| **CDN 缓存** | 边缘缓存静态资源 | 可选 | 主站已有 EdgeOne；全站再套 CF 会双 CDN |
| **Universal SSL** | 自动 HTTPS | 有橙云才相关 | |
| **DDoS 缓解** | 网络层清洗 | 要进 CF 路径 | Free 有基础能力 |
| **WAF（基础）** | 托管规则 + 少量自定义规则 | 要橙云 | Free 规则数有限；Pro 才更全 |
| **Bot Fight / 基础机器人** | 挡简单爬虫 | 要橙云 | |
| **Page Rules / Redirect** | 跳转、缓存例外 | 可选 | Free 条数很少 |
| **Analytics** | 流量概览 | 可选 | |

### B. 「大善人」核心：存储与出站（最贴图床）

| 能力 | 免费大概量（常驻额度，以官网为准） | 对本站 |
|---|---|---|
| **R2 对象存储** | ~10 GB 存储；写/列约 100 万次/月；读约 1000 万次/月；**Egress $0** | **图床首选** |
| **Images** | 变换有免费额度；存图多在付费档 | 可后做缩略图；先 R2 够用 |
| **Stream** | 视频 | 博客暂不需要 |

评论插图、文章外置大图、以后摆脱乱第三方图床 → **R2 + `img.threetwoa.live`**。

本仓历史：Waline/Giscus 曾试第三方图床失败；COS 已有评论大图链路。R2 可作**第二图床**或逐步统一外链图，不必一天替换 COS。

### C. 计算与站构建（本仓已有备选）

| 能力 | 免费大概量 | 对本站 |
|---|---|---|
| **Workers** | ~10 万请求/日；CPU 很短 | 可选：上传签名、img 路由、地理调度 |
| **Pages** | 静态托管 | 已用 Vercel；不必再迁 |
| **KV / D1 / DO** | 有免费额度 | 玩具/计数可以；主站非刚需 |
| **Astro CF adapter** | `CF_WORKERS=1` | 仓库已有；**主链路不用** |

### D. 和「国内」相关的现实

| 能力 | 现实 |
|---|---|
| 大陆节点 CDN | Free/普通橙云 **不能**当国内加速方案 |
| 与 EdgeOne 分工 | **主站 EO**；**图床/部分防护 CF** |
| 若主站也橙云 | 国内可能多一跳，且要小心和 EO 回源循环 |

## 和早前讨论的对应关系

| 曾讨论点 | CF 侧落点 |
|---|---|
| 自定义域名 | 域名本身在 Name.com；CF 可托管 DNS，不是域名注册商替代 |
| 国内加速 | **EdgeOne**，不是 CF |
| 图床 | **R2**（大善人点）；Images 可选 |
| 防网络攻击 | 橙云 + Free WAF/DDoS；或仅护 `img` 子域 |
| 调度 CN/海外 | Workers（可选，非本质） |
| 评论图 | 可继续 COS；新图也可写 R2 |

## 建议采用的「本站 CF 画像」

```text
Cloudflare = 图床（R2）+ 子域防护 +（可选）DNS 面板
EdgeOne    = 主站国内向加速
Vercel     = 构建与源站
```

不要把 CF 理解成「免费替代国内 CDN 的大善人」——那是错的；  
把它理解成「**免出站的对象存储 + 免费边缘防护工具箱**」——这才是对本站值钱的部分。

限额以 [Cloudflare 定价页](https://www.cloudflare.com/plans/) / [R2 Pricing](https://developers.cloudflare.com/r2/pricing/) / [Workers limits](https://developers.cloudflare.com/workers/platform/limits/) 为准；本文数字为决策用近似。
