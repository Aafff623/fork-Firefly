### EdgeOne 个人版 · 应用满的能力（别浪费）

> 选型对比见[官方文档](https://cloud.tencent.com/document/product/1552/94165)；以控制台实际套餐页为准。

| 能力 | 个人版大致含 | 本站用法 |
|---|---|---|
| 安全加速流量 | **50 GB/月** | 主站 HTML/静态经 EO；**大图尽量别全走 EO**（省配额） |
| 安全加速请求 | **300 万次/月** | 博客够用 |
| 可接入站点 | **1 个** | 已用：`threetwoa.live` |
| 子域名 | 最多约 **200**/站 | `www` + apex 已占；`img` **不要**再占 EO，留给 CF |
| HTTPS 证书 | 免费托管证书 | 已部署 |
| 平台基础 DDoS | 有（超阈值清洗等） | **主站防护靠它** |
| 基础访问管控 / CC / 漏洞规则集 | 个人档含基础项 | 主站 WAF 类需求先挖 EO，不另买 |
| 加速区 | 现为「不含中国大陆」 | 含大陆 → Phase ICP，不另购套餐档（仍是个人版改区域） |

**含义：** 每月这笔 EO 费买的是「主站 CDN + 基础安全」。  
Cloudflare **不要再为同一主站路径付第二份 CDN/WAF**。

## 2. 优化后架构（对照权益）

```text
【已付月费 · 用满】
  www / @  → EdgeOne 个人版（50GB/300万次 + 基础安全）→ Vercel

【免费补齐 · CF】
  img.     → Cloudflare 橙云 → R2（免出站）

【后续优化 · 不挡现在】
  ICP 后把同一 EO 套餐加速区改为含大陆（仍个人版，不升档除非流量爆）
```

### 流量怎么省 EO 配额（你在按月续费）

| 内容 | 建议路径 | 理由 |
|---|---|---|
| 页面、JS/CSS、站内小图 | EdgeOne | 套餐本职 |
| 评论大图、相册外链、用户上传 | **R2 / `img.`** | 不吃 EO 50GB；R2 出站免费 |
| 壁纸/大视频 | 勿经 EO 瞎推 | 易打穿个人版流量 |

## 3. 月费纪律

| 做 | 不做 |
|---|---|
| 保留 EO 个人版续费（国内主链刚需） | 再买基础版/标准版「为了安心」 |
| 控制台确认自动续费金额（9.9 vs 29.9） | 结账页乱勾 COS/CDN 搭配包 |
| CF 全程 Free + R2 免费额度 | 上 CF Pro「和 EO 叠主站防护」 |
| 超额前看 EO 用量面板 | 无监控导致后付费流量暴击 |

**现金刚需：** 实质就是 **EdgeOne 个人版月费**（其余目标 $0）。

## 4. 分阶段

### Phase 1 · 已完成

EO 个人版已承接主站；权益开始消耗流量/请求——正常。

### Phase CF · 用 CF 补 EO 不擅长/不划算的部分

| 步 | 动作 | 与权益关系 |
|---|---|---|
| CF-1 | CF 加站 | 免费 |
| CF-2 | R2 + `img.threetwoa.live` 橙云 | **把大图移出 EO 50GB** |
| CF-3 | Free WAF 护 img | 不替代 EO 主站安全 |
| CF-4 | 新图写 R2；COS/EO 降载 | 省 COS + 省 EO |
| CF-5/6 | Workers 签名 / NS 可选 | 免费额度内 |

主站 **www 不进 CF 橙云**——避免「月费 EO + 又经 CF」双层，且国内跳数增加。

### Phase ICP · 后续

同一个人版改加速区；见 `edgeone-mainland-icp-plan.md`。
