# EdgeOne 大陆顶级加速 · 后续优化方案（Phase ICP）

> **状态**：📋 后续优化 / 不阻塞当前站点  
> **写入日期**：2026-08-12  
> **前提**：Phase 1 已通（`https://www.threetwoa.live` → EdgeOne 不含大陆 → Vercel）  
> **官方**： [EdgeOne 域名 ICP FAQ](https://cloud.tencent.com/document/faq/1552/110835)

## 一句话目标

备案通过后，把 EdgeOne 加速区从「全球不含中国大陆」升级为「全球可用区」或「中国大陆可用区」，让同学走**大陆节点**，而不只是「能打开」。

## 为什么现在不做

| 原因 | 说明 |
|---|---|
| 合规 | 未 ICP 不能选含大陆加速区 |
| 转出锁 | `threetwoa.live` 约 2026-08-11 注册于 Name.com，ICANN 约 60 日内部可转出（估 **2026-10-10** 起） |
| 后缀待验 | `.live` 是否被腾讯云/管局接受备案，需进备案系统试填确认 |
| 接入 | 源站在 Vercel（海外）时，个人备案常仍需境内云资源作为接入（如轻量 CVM） |

当前 Phase 1 已解决「vercel.app 污染导致打不开」；大陆机房级加速是**质量升级**，不是上线阻塞项。

## 架构（优化后）

```text
访客（国内）
  → threetwoa.live / www
  → EdgeOne（含中国大陆节点）
  → 回源 Vercel（或按规则分源）

可选：Cloudflare / DNSPod 仍只做调度，不承担大陆源站
```

## 执行大纲（解锁后）

```text
① 确认 .live 可备案；否则另购 .com/.cn 并迁移主入口
② Name.com → 境内注册商（建议腾讯云）转入 + 实名一致
③ 腾讯云账号实名 = 域名所有者 = 备案负责人
④ 按系统要求购置境内备案用轻量资源（若需要）
⑤ 提交个人 ICP → 初审 → 管局审核 → 拿备案号
⑥ EdgeOne 站点加速区改为「全球可用区」或「中国大陆可用区」
⑦ 国内多运营商测速；评估个人版流量是否够用
⑧ 更新 CONTEXT / runbook 现状行；对外可宣称「大陆节点加速」
```

## 材料预收集（个人 · 有空再备）

- 身份证正反面  
- 本人手机号、紧急联系人  
- 网站名称与简介（个人博客、非经营性）  
- 域名实名与证书截图  

## 明确不做

- 未备案强切含大陆  
- 为备案重开 EdgeOne Pages 构建  
- 未确认 `.live` 可备就批量购买无关产品
