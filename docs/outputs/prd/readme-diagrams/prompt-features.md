# Features — 反推 Prompt

模块化、图标统一、信息密度高。4–6 色。

## 系统指令

```text
Professional features overview diagram for GitHub README.
Modular cards or columns. Uniform flat icons (same stroke weight).
Short title + one-line description per feature. High scannability.
White/light background. ≤6 colors. Consistent corner radius and spacing.
NO: long paragraphs in cards, mismatched icon styles, decorative clutter, fake logos.
```

## § module-pack（标杆：`features/infographic-modules-pack.png`）

```text
[系统指令]
Infographic module pack style: 4–8 feature cards in a clean grid or columns.
Each card: rounded icon tile (teal/navy/orange accents from a fixed palette) + bold label + ≤12-word blurb.
Optional numbered steps if features are sequential.
Project features (use ONLY these):
1. [name] — [blurb]
2. ...
```

## § mindmap-branch（标杆：`features/tree-flow-mindmap-trio.png` 中 mind map 区）

```text
[系统指令]
Radial mind-map style for feature groups from a center hub "[PRODUCT]".
3–5 thick color-coded branches; short leaf labels; tiny consistent icons.
Keep flat and tidy; not organic scribble chaos.
Hub + branches mapping:
[...]
```

优先 § module-pack；能力分组多时用 mindmap。
