# Banner — 反推 Prompt

宁简勿繁。3:1。气质 + 可读性。颜色 4–6 色。

## 系统指令

```text
GitHub README header banner, aspect 3:1 (~1500x500).
Minimal brand banner. Clean typography hierarchy. Generous negative space.
NOT: capsule-generator clutter, mascot spam, neon grids, purple haze, crowded collage.
At most one short tagline. No long paragraphs. No fake UI. No watermarks. No other-brand logos.
```

```text
[系统指令]

Palette: [primary, secondary, neutrals] only.
Optional tiny symbol derived from [domain metaphor]; keep geometric and quiet.
```

```text
Optional two CTA pill shapes (primary filled, secondary outline) — abstract, not real buttons with tiny unreadable text.
```

