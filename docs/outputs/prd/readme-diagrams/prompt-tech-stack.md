# Tech-stack — 反推 Prompt

与 `architecture.png` 分工：本图展示 **技术选型 / 分层栈**，不是部署蜘蛛网。

## 系统指令

```text
Professional tech-stack diagram for GitHub README.
Either (A) uniform icon wall with labels, or (B) layered horizontal stack bars.
Only include technologies that actually exist in the project.
Consistent icon language (same style family). ≤6 colors. White background preferred.
NO: inventing vendors, rainbow icons, photoreal logos with wrong brands, cluttered 3D mess unless matching chosen reference style exactly.
```

## § icon-wall（标杆：`tech-stack/icon-wall-slidestack.png`）

```text
[系统指令]
Icon wall on clean white card: grid of technology category icons with labels under each.
Unified lighting and palette (blues/oranges/grays). Glossy isometric OR flat — pick ONE and stay consistent.
Categories to show (map real tools under each):
- Frontend: [...]
- Backend: [...]
- Database: [...]
- Infra/DevOps: [...]
- Other: [...]
Title optional: "Tech Stack".
```

## § layered-bars（可与 architecture layered 呼应，但只列技术名）

```text
[系统指令]
Horizontal layered bars top→bottom: Presentation / Application / Data / Infra.
Inside each bar: 2–6 real tech names as small chips/pills.
Blue/gray professional palette. Clear Request↓ Service↑ optional side arrows only if helpful.
```

禁止与 architecture 图使用完全相同的服务拓扑构图。
