# 企业招用高校毕业生补贴政策核实（2026-08-06）

> 调研范围：一次性扩岗补助、小微企业社保补贴、重点群体税收扣减、创业担保贷款；并对照网上「应届生三千 + 1500 补贴 ≈ 免费、用完换一批」类说法。  
> 原则：以一手/官方或权威转载为准；查不到标「未核实」；不编造。

---

## 结论先行

| 主张 | 判定 | 一句话 |
|---|---|---|
| 1. 一次性扩岗补助约≤1500、缴满3个月、同一人一家企业仅一次、2025–2026仍延续 | **真**（金额为「上限」，部分地区低于1500） | 政策属实；补助发给**企业**，一次性；2026年已延续至年底。 |
| 2. 小微企业招用高校毕业生社保补贴（企业缴纳部分，约1–2年） | **部分真** | 补贴企业缴纳部分属实；**全国办法多为最长1年**，「约1–2年」易与灵活就业补贴（最长2年）或个别地方加码混淆。 |
| 3. 税收扣减每人每年6000、可上浮30%、最长3年、执行到2027年底 | **部分真** | 数字与期限属实；**企业招用侧不等于「凡招应届生即可」**，须为脱贫人口或登记失业半年以上并持证人员等。 |
| 4. 小微企业新招高校毕业生达比例可贷最高400万并贴息 | **真**（有比例与信用门槛） | 额度与贴息框架属实；须达到新招用符合条件人员比例等，非「招几个应届生就能贷」。 |
| 5. 「三千工资 + 1500≈免费、用完换一批」段子 | **夸张 / 未形成大规模统一梗** | 政策存在被营销号「白嫖」化；**1500是一次性给企业**，无法冲抵月薪；同一人不可重复申领扩岗补助。 |

**对「免费劳动力」叙事的总评**：政策真实存在且近年连续延续，但把一次性扩岗补助与低薪叠加成「≈免费」「用完换一批」，在金额量级、申领约束、劳动用工义务上均属夸大。

## 四项政策核实表

### 1. 一次性扩岗补助

| 项 | 核实结果 |
|---|---|
| **判定** | **真** |
| **关键条件** | 招用**毕业年度**及**离校两年内未就业**高校毕业生，和/或**16–24岁登记失业青年**；签订劳动合同；为企业为其足额缴纳**3个月以上**失业、工伤、职工养老保险费（以现行文件表述为准）。机关事业单位一般不适用；同一人员身份信息**只能享受1次**，不得跨企业、跨年度、跨地区、跨资金渠道重复享受；通常与一次性吸纳就业补贴等不重复。 |
| **金额** | 国家口径：**每招用1人不超过1500元**（上限）。多地按1500元执行；亦有地方按1000元（如部分年度北京、安徽等地通告）。 |
| **期限 / 执行到哪一年** | 人社部发〔2024〕44号等框架下多地执行至**2025-12-31**；2026年四部门通知明确延续，**执行期限 2026-01-01 至 2026-12-31**。 |
| **资金去向** | 发给**企业**（对公账户等），不是发给毕业生本人。 |
| **出处 URL** | ① 四部门全文转载（新疆人社厅，来源：人力资源和社会保障部）：https://rst.xinjiang.gov.cn/xjrst/c112737/202607/1f70909da8cd4a4eabbbe1c42593a754.shtml （《关于失业保险支持企业稳岗扩岗的通知》，人社部发〔2026〕39号，2026-06-18）  
② 权威解读（同来源）：https://rst.xinjiang.gov.cn/xjrst/c112675/202607/e893d6c5ba5147208141c40626e3df44.shtml  
③ 人社部规范性文件目录条目（索引号 717823004/2026-00024）：http://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zcfg/gfxwj/  
④ 地方延续示例（上海，2025年1500元/人，澎湃转载）：https://www.thepaper.cn/newsDetail_forward_30790179 / https://edu.sina.com.cn/l/2025-05-09/doc-inevyhfv9151639.shtml  
⑤ 黑龙江省政府网站政策问答（合并实施、≤1500、至2025年底）：https://www.hlj.gov.cn/hlj/c116413/202406/c00_31745452.shtml |

### 2. 小微企业招用高校毕业生社保补贴

| 项 | 核实结果 |
|---|---|
| **判定** | **部分真** |
| **关键条件** | **小微企业**招用**毕业年度**和**离校2年内未就业**高校毕业生；签订**1年以上**劳动合同并缴纳社会保险费。 |
| **金额** | 按企业为毕业生**实际缴纳**的基本养老、基本医疗、失业保险等（各地细则略有差异）给予补贴，**不包括个人应缴纳部分**；属「先缴后补」。 |
| **期限** | 《就业补助资金管理办法》（财社〔2023〕181号）：小微企业该项补贴**最长1年**。灵活就业高校毕业生本人社保补贴最长不超过**2年**——易被混称为「1–2年」。个别地市宣传更长期限时，需单独核对当地文件（本调研未把「全国统一2年」坐实）。 |
| **执行到哪一年** | 作为就业补助资金常规支出项目持续实施；具体年度细则以地方人社/财政通知为准。全国办法现行依据为财社〔2023〕181号（修订后施行）。 |
| **出处 URL** | ① 财社〔2023〕181号全文转载（安庆市宜秀区政府网站）：http://www.ahq.gov.cn/xwzx/tzgg/202502/t20250228_2542024.html ——明确「给予最长1年的社会保险补贴，不包括高校毕业生个人应缴纳的部分」  
② 税屋转载同文：https://www.shui5.cn/article/b3/184889.html  
③ 黑龙江省政府网站问答：https://www.hlj.gov.cn/hlj/c116413/202409/c00_31771185.shtml  
④ 漳州市政府告知（最长不超过1年）：http://www.zhangzhou.gov.cn/cms/html/zpxrmzf/2025-03-17/793639365.html |

### 3. 税收扣减（重点群体创业就业）

| 项 | 核实结果 |
|---|---|
| **判定** | **部分真**（数字真；适用对象常被网文写宽） |
| **关键条件（企业招用侧）** | 企业招用**脱贫人口**，以及在人社公共就业服务机构**登记失业半年以上**且持《就业创业证》或《就业失业登记证》（注明「企业吸纳税收政策」）的人员；签订**1年以上**劳动合同并依法缴纳社保。  
**注意**：「毕业年度内高校毕业生」出现在公告**个体经营**条款的重点群体列举中；**不等于**企业招用任意应届生即可扣减。媒体常把「登记失业半年以上的高校毕业生」简化成「招用高校毕业生」。 |
| **金额** | 定额标准**每人每年6000元**，最高可上浮**30%**（地方可定，如7800元）；依次扣减增值税、城建税、教育费附加、地方教育附加和企业所得税；当年扣减不完**不得结转下年**。 |
| **期限** | 自签订劳动合同并缴纳社保当月起，**3年内**；政策执行期 **2023-01-01 至 2027-12-31**；2027年底未满3年的可继续享满3年。 |
| **出处 URL** | ① 财政部等四部门公告2023年第15号全文（苏州市财政局转载）：https://czju.suzhou.gov.cn/czj/jsjf/202401/56944e4881464cbfb22c2b9e01fb6157.shtml  
② 青岛市税务局转载：http://qingdao.chinatax.gov.cn/ssfg2019/zxwj/202308/t20230803_81313.html  
③ 云南省人民政府门户转载：https://www.yn.gov.cn/ztgg/lqhm/lqzc/gbhqwj/202308/t20230808_275274.html  
④ 新华社/权威媒体报道（31省市顶格落实）：https://finance.sina.com.cn/jjxw/2023-12-05/doc-imzwxqsv6636121.shtml |

### 4. 创业担保贷款（小微企业吸纳就业）

| 项 | 核实结果 |
|---|---|
| **判定** | **真**（有明确门槛） |
| **关键条件（常见国家口径）** | 属小型、微型企业；申请前**1年内**新招用符合创业担保贷款申请条件的人员（**含高校毕业生等**）达到现有在职职工人数**10%**（超过100人的企业达到**5%**）；签订1年以上劳动合同；无拖欠工资、欠缴社保等严重违法违规信用记录等。 |
| **金额 / 期限 / 贴息** | 小微企业贷款额度上限由300万提高到**400万元**（财金〔2023〕75号框架）；期限常见**不超过2年**；符合条件的可获财政对贷款实际利率**50%**贴息（地方细则可能微调）。 |
| **执行到哪一年** | 《普惠金融发展专项资金管理办法》自2023-10-01起施行，**实施期限5年**（即约至2028年）；各地实施办法滚动更新，具体以最新省级细则为准。 |
| **出处 URL** | ① 财金〔2023〕75号（税屋转载）：https://www.shui5.cn/article/be/179635.html  
② 合川区政府政策摘录（依据财金〔2023〕75号，最高400万）：http://www.hc.gov.cn/xxgk/zfxxgkmlrk/sqyhzcxx/lxhyly/rzxd/js/202310/t20231019_12446053.html  
③ 新浪财经转载甘肃实施办法（10%/5%、400万、2年）：https://finance.sina.com.cn/jjxw/2024-10-24/doc-inctqnpt3246729.shtml

## 段子与现实对照

### 网上典型说法（检索摘要）

检索词包括：「应届生三千 1500补贴」「扩岗补助 用完换一批」「应届生 白嫖 扩岗」等。

| 类型 | 典型说法 | 检索所见 |
|---|---|---|
| 营销号 / 标题党 | 「招个应届生白嫖××万补贴」「入职3个月老板领1500≈免费试用期」 | 可见，如头条类稿件《HR打死不说!招个应届生白嫖1.2万补贴…》（https://www.toutiao.com/article/7480039857272783369/）——把多项补贴叠加夸大，且把发给企业的一次性补助说成「免费试用」。 |
| 政策科普 | 「招1人补1500」「企业领补贴」 | 大量人社/政务媒体正常解读，非吐槽梗。 |
| 「三千 + 1500 ≈ 免费」「用完换一批」固定句式 | 假定月薪3000、用扩岗补助冲抵、满期换人 | **未核实到**大规模、统一、可复现的梗库或权威媒体专题报道；更像零散吐槽/自媒体话术，而非全民统一模因。 |

**结论（主张5）**：**未形成大规模统一梗**；存在「补贴羊毛 / 白嫖应届生」类自媒体叙事，但「三千工资 + 1500补贴 ≈ 免费劳动力、用完换一批」作为固定段子**证据不足**，且与政策结构不符。

### 现实对照（为何夸张）

| 段子暗示 | 政策现实 |
|---|---|
| 1500 抵掉工资 | 扩岗补助是**一次性、发给企业**；相对月薪3000量级极小，且**不能替代发薪义务**。 |
| 用完换一批继续薅 | **同一人员身份只能享受1次**扩岗补助；换企业也不能重复用同一人身份；另有社保缴费、合同、审计公示约束。 |
| 招人≈零成本 | 即使叠加小微企业社保补贴（通常最长1年、仅单位部分），企业仍须支付工资、个人社保、管理成本；税收扣减另有身份门槛与税额上限。 |
| 「免费劳动力」 | 受《劳动合同法》等约束；恶意短期用工规避义务可面临劳动争议与诚信惩戒。本调研**未核实**全国层面「系统化用完换一批」的官方通报规模。 |

## 剩余不确定项

| 项 | 说明 |
|---|---|
| 人社部官网正文直链 | 已确认目录页存在「人社部发〔2026〕39号」条目；本次抓取以新疆人社厅转载的**人社部来源全文**为准。若需 PDF 原件，可再打开 mohrss.gov.cn 对应详情页。 |
| 「约1–2年」社保补贴 | 全国办法对小微企业招用毕业生多为**最长1年**；个别城市（如东莞本地宝等非法规库渠道宣传「最长2年」）**未在本文件中用省级正式规章坐实**，标为地方差异待核。 |
| 「三千 + 1500」固定段子流行度 | 公开搜索未见权威统计或大规模统一梗证据；社交平台私域/短视频口播可能遗漏，标**未核实为大规模统一梗**。 |
| 人社部发〔2024〕44号全文 | 多地经办通知引用该文；本次未单独下载 PDF 全文，关键条款以各地转述 + 2026年新通知为准。 |
| 「用完换一批」是否构成违法用工模式 | 属个案执法问题；本调研未检索到可引用的全国性专项查处通报。 |
