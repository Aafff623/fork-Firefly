文章横幅 · description 叠层样式预览

这是封面大标题下方的摘要叠层（frontmatter description），不是正文里的 blockquote。

五套方向用同一标题、同一句文案；挑好看的，回信写代号即可。

A 去框只留字

去掉玻璃盒、边框、引号；只留细分隔 + 白字阴影。封面露得最多。

对话即代码：Vibe 入门坐标
