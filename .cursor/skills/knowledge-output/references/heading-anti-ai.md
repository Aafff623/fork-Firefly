# 小节标题防 AI 味（范例库）

机器门禁在 [`../../_shared/post-redlines.md`](../../_shared/post-redlines.md) + `validate_post.py`。本表只给人起名对照。

成帖扫 H2/H3 时对照本表。原则：先想这节在干什么（现象 / 根因 / 解法 / 选择 / 安装 / 附件），再取名。侧栏目录窄，宜短。完整点题，不要感想句，也不要空对象。H2 不能空到看不出对象。成帖句子要有主语，禁止大段无主语句。

大标题（frontmatter `title`）另守 [`../../_shared/post-redlines.md`](../../_shared/post-redlines.md)：园主给了素材题/方向就先对齐，不要先写金句。

完整清单可随踩坑追加；命中「禁」列就改名。

## 禁：收尾 / 总结腔（重灾区）

| 别这么起 | 为啥腻 | 可以改成（方向） |
|---|---|---|
| 一句话收束 / 一句话结论 / 一句话总结 | 「一句话 X」是模型最爱贴的标签 | 直接写判断：`认清撞上哪一层就行` |
| 总结一下 / 小结 / 本章小结 | 课件腔 | `写完之后我怎么选` / `这锅扣在哪` |
| 核心要点 / 关键收获 / Key Takeaways | 英文 SEO 博客翻版 | `带走这三条就够`（若真要列）或干脆并入上节 |
| 综上所述 / 总而言之 / 简而言之 | 作文结尾 | 删标题，末段直接说完 |
| 写在最后 / 最后想说 / 结语 / 结束语 | 空洞仪式感 | `适合谁，不适合谁` / `别踩的坑` |
| 值得注意的是…（当标题） | 套话开口 | 换成具体风险名 |
| In conclusion / To summarize / The key takeaway | 英文 AI 收尾标配 | 同左：具体判断句 |

## 禁：感想句大标题（title，不是 H2）

| 别这么起 | 为啥废 | 可以改成（方向） |
|---|---|---|
| 没废 / 带歪了 / 这回算踩中了 | 感想句，侧栏和列表卡看不出讲什么 | 对齐园主素材题：对象 + 现象 + 交付物 |
| 金句先行、题面后补 | 园主已经给了方向还去炼句 | 先写完整题，钩子留给正文第一句 |

## 禁：空对象 H2（没说清在讲什么）

| 别这么起 | 为啥废 | 可以改成（方向） |
|---|---|---|
| 揭秘两阶段 | 「两阶段」是什么的两阶段？ | `社区解法：先藏两工具再放开` |
| 内置的和社区的 | 内置/社区的什么？ | `DSH 出厂插件和社区插件的选择` |
| 先看掉在哪 / 再放开 | 掉的是分数还是权限，没点名 | `先看 V4 Pro 分数掉在哪` |
| 装法是拷目录 / 对不上就停 | 没主语，看不出谁装谁停 | `园丁怎么装社区 preset` |
| 每节硬塞「园丁」「园主」 | 称呼可用，当装饰就腻 | 读者=园丁、作者=园主；节名仍写职能 |

## 禁：空心脚手架标题

| 别这么起 | 可以改成（方向） |
|---|---|
| 概述 / 简介 / 背景介绍 / Overview | `先把名字对齐` / `官网到底卖哪档` |
| 什么是 XX（空泛） | `XX 在官方页面上长什么样` |
| 深入探讨 / 全面解析 / 深度剖析 | 删掉副词，写对象：`Account Manager 在链路里干嘛` |
| XX 清单 / XX 全览 / N 大要点 | 课件路牌；改成现场判断：`这三处我会改` |
| XX 实录（当空标题） | 真有现场再写 `踩坑现场`，不要当目录名 |
| 未来展望 / 挑战与机遇 / 小结与展望 | 有具体未决问题再写：`还没测到的两块` |
| 最佳实践 / Best Practices（无场景） | `我现在会怎么配` / `这几条我验证过` |
| Let's dive in / 让我们开始吧 | 直接第一节进货 |

## 禁：正文里的标签句（常跟烂标题成套）

这些不一定是 H2，但成帖时一并清掉：

- 「一句话说」「一句话版本」「用一句话概括」
- 「需要注意的是」「值得一提的是」「不难发现」
- 「在当今快速发展的…」「赋能 / 抓手 / 闭环」（空转时）
- 「I hope this helps」「Happy coding!」式英文客服收尾

## 赞：站内已有的活人标题（抄气质，别抄字面）

| 好例子 | 出处气质 |
|---|---|
| `先把段子拆开` | 有动作、有对象 |
| `踩坑现场` | 像日记不是白皮书 |
| `对你（CC Switch 环境）最硬的一道坎` | 点名读者场景 |
| `壳像中转，货仍是羊毛号池`（作句可，作标题也行） | 有对立、有判断 |
| `终幕：一切归于薅羊毛` | 有叙事位置，不叫「结论」 |
| `适合谁 & 我的判断` | 人话 + 立场 |
| `DSH 出厂插件和社区插件的选择` | 对象完整，职能是「选择」，没有尾巴 |

## 自检口诀

1. 大标题：不看正文，能不能说出这篇在讲什么？感想句直接废。  
2. H2：先能回答「这节是现象 / 根因 / 解法 / 选择 / 安装 / 附件哪一种」，再取名。  
3. 删掉标题后，第一节第一句是否还在复读标题？（复读就删暖场句）  
4. 同帖多个「总结/要点/注意」→ 合并或改成具体名词。  
5. 结尾节优先用**判断 / 边界 / 怎么选**，少用**收束 / 总结 / 要点**。  
6. 句子要有主语。禁止大段无主语句。H2 不能空到看不出对象。
