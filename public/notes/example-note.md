# 示例笔记：在博客里嵌入 Markdown 附件

这是一段用于测试 `::note` 引用卡片的示例笔记。它放在 `public/notes/` 下，卡片会在构建时自动读取标题、摘要、大小与行数。

## 这个功能能做什么

- **引用框**：像 GitHub 卡片一样展示笔记标题、摘要与元信息
- **下载**：右上角按钮直接下载原始 `.md` 文件
- **预览**：点击卡片主体弹窗查看笔记全文

## 代码块示例

```js
const greeting = 'hello, note card';
console.log(greeting);
```
