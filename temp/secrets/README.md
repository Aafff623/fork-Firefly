# secrets/ — 本地敏感配置与密钥备份

只记录**分类、用途、存放位置、轮换信息**；任何 Secret 值（Token / Secret Key / 密码）不得写进本文件。

## 约定

- 每个服务一个子目录（首次使用时创建）：`cloudflare/`、`r2/`、`vercel/`、`github/`、`edgeone/` …
- 备份文件命名：`<用途>.<日期>.env` 或 `<用途>.<日期>.json`，例如 `r2-comment-bucket.2026-09-02.env`
- 每条记录包含：服务、账号标识（邮箱/账号名，不是密钥）、endpoint、用途、轮换日期、存放文件名
- 轮换后：更新本文件的轮换日期，旧文件删除或改名归档
