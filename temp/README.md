# temp/ — 项目统一临时工作区

本目录是 Agent 与园主的**唯一**临时试验区：临时脚本、调研材料、交接快照、验证预览、日志、缓存、密钥备份都放这里，禁止散落到项目外（C 盘、D 盘根等）或项目正式目录。

除下面 4 个入口文件进入 Git 外，**本目录其余内容全部被忽略、永不提交**：

- `README.md`（本文件）
- `AGENTS.md`（Agent 行为规则）
- `.gitignore`（目录自身防护）
- `secrets/README.md`（密钥分类与轮换说明，不含 Secret 值）

## 分类

| 子目录 | 放什么 |
|---|---|
| `input/` | 用户提供的原始资料、下载文件、待分析输入（按 `<task-slug>/` 分目录） |
| `research/` | 临时调研材料、网页抓取、参考仓库克隆、灵感草稿 |
| `scripts/` | 一次性脚本、实验工具、格式转换脚本 |
| `preview/` | 临时 HTML/CSS/JS、验证截图、视觉检查素材 |
| `reports/` | 临时调研报告、对比分析、评估记录 |
| `handoff/` | 仅保留当前未完成任务的最新交接（每个任务一份，覆盖式更新，不堆历史） |
| `logs/` | 调试日志、命令输出、hook 运行记录 |
| `cache/` | 可随时删除的构建缓存和中间产物（如本地构建的 dist） |
| `gallery-inbox/` | 照片墙待上墙素材；仅在园主点名后写入 `public/gallery/` 或 `galleryConfig.ts` |
| `secrets/` | 本地敏感配置与密钥备份；README 记录分类和轮换信息，**不记录 Secret 值** |

子目录在首次使用时才创建，不预铺空壳。

## 生命周期

- 任务结束后按 `task-slug` 集中清理；`cache/` 里的东西随时可整目录删。
- handoff 只服务于未完成且需要继续的任务；任务完成、合并、取消或被后续方案替代后，立即删除对应 handoff。
- reports / research 只保留仍支撑当前决策或未完成工作的材料；结论已吸收到正式文档且不再复用时删除。
- logs / preview / cache 都是验证中间物，不是历史档案；本轮验证结束后按任务清理。
- 已确认要长期保留的内容，迁移到项目正式目录（`docs/`、`scripts/` 等），不留在 temp。
- 本目录不是文档仓、不是资产仓、不是备份仓。

## 密钥边界

`secrets/` 被 `.gitignore` 忽略，但**忽略 ≠ 加密**：不要把密钥写进任何会进入 Git、日志、聊天回复的文件。密钥的分类、存放位置、轮换时间记录在 `secrets/README.md`。
