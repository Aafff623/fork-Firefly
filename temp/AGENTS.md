# temp/ Agent 规则

进入本目录（或产出临时文件）的 Agent 必须遵守：

1. **所有临时产物一律放 `temp/`**，按 `README.md` 的分类落位，按任务建 `<task-slug>/` 子目录。禁止把临时脚本、调研材料、截图、日志写进项目正式目录或项目外路径（C 盘、D 盘根等）。
2. **只保留一个临时区**：本仓不再使用 `.scratch/`、`tmp/` 等旧目录名；看到旧路径引用时以本目录为准。
3. **长期价值外迁**：确认要长期保留的报告、脚本、决策，移入 `docs/`、`scripts/` 等正式位置；temp 不是归档层。
4. **密钥规则**：密钥、Token、敏感配置备份只放 `secrets/`，并确保 `.gitignore` 覆盖；禁止把 Secret 值写入任何入库文件、`AGENTS.md`、MCP 配置、日志或对话回复。`secrets/README.md` 只记录用途 / endpoint / 账号标识 / 轮换信息。
5. **handoff 覆盖式**：`handoff/` 下每个未完成任务只保留一份最新交接，不积累历史快照；任务完成、合并、取消或被后续方案替代后立即删除；内容须区分「已验证事实 / 推断 / 待确认」。
6. **报告按需留存**：`reports/`、`research/` 只保留仍支撑当前决策或未完成工作的材料；结论已吸收到正式文档且不再复用时删除。
7. **清理须确认**：删除他人或历史批次前先向园主确认；自己本次任务产生的文件自行收尾。
8. **不把 temp 当工作目录跑长驻服务**：dev server、守护进程的运行时状态不要落在 temp（会被误清）。
