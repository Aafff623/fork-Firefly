## What's new

**v1.3.0** is the delivery, Ask, and mobile-performance release after `v1.2.0`.

Production: https://www.threetwoa.live

Vercel fallback: https://fork-firefly.vercel.app

### Highlights

**Production delivery**

- The public path is now explicit: `www.threetwoa.live` → EdgeOne CDN → Vercel origin.
- Cloudflare is the authoritative DNS provider and hosts `img.threetwoa.live` on R2 for article and comment images.
- Vercel and EdgeOne now use separate cache policies for HTML, `/_astro/*`, Pagefind, assets, and `/api/*`.
- The EdgeOne Pages adapter remains available for compatibility testing, but it is not the current production host.

**Ask and LiveChat**

- Added a HeroUI Pro React Ask island with personas, site retrieval, source-aware prompts, and streamed responses.
- Added a pet-triggered LiveChat widget using the same server-side Ask proxy.
- Browser requests stay on `/api/ask`; the MaxKB access token remains server-only.
- Ask is intentionally DEV-only for now. Production routes and API calls return 404 until the cloud plan is approved and configured.

**Performance and mobile UX**

- Continued the Swup lifecycle and load-strategy work from `v1.2.0`.
- Mobile no longer behaves like a scaled-down desktop: decorative RepelText and TagCloud work are removed, duplicate metadata requests are avoided, redundant bottom-sidebars are skipped, and long controls collapse to icon-sized controls.
- Current V3 trend results: mobile LCP `3241 → 2221 ms` (-31.5%), mobile DOM nodes `3597 → 3015` (-16.2%), forced layout `3734 → 2590 ms` (-30.6%), TagCloud reflow `723 → 140 ms` (-80.6%), and CLS `0`.
- LCP values compare an older online build with the current localhost build and are directional, not a strict same-environment A/B benchmark.

**Content and authoring**

- Published new Knowledge batches, Agentic Coding notes, career/interview notes, collection indexes, and matching dynamics.
- Added AI Morning Brief and GitHub Weekly Hot authoring skills and registered their collections and taxonomy.
- Added or expanded collections for CSDN tutorials, xiaolincoding, Vibe Coding, and related indexes.

**Polish and fixes**

- Restored the footer to an independent bamboo-green garden palette, replaced the purple-tinted scape, and compacted the mobile/tablet footer so it is not a scaled-down desktop block.
- Added a shared paper safety layer on collection cards so titles stay readable on both dark photos and high-frequency illustrations.
- Replaced the calendar's mixed landscape/pixel pool with three 3D voxel character loops; hover and keyboard focus pause the rotation.
- Added R2-backed comment-image upload and object cleanup while retaining the COS compatibility path.
- Hardened Ask token handling, API cache boundaries, dynamic inline comments, and framework compatibility.
- Hid demo content from production-facing lists and refreshed affected LQIP metadata.

### Upgrade

No intentional breaking change.

```bash
pnpm install
pnpm check
pnpm type-check
pnpm build
```

Requirements remain Node.js ≥ 22 and pnpm 9. For image uploads, configure the server-only `R2_*` variables from `.env.example`; the existing `COS_*` path remains a fallback. Ask requires `MAXKB_ACCESS_TOKEN` and an approved production enablement change.

### Validation and limits

- Vercel Production is Ready and follows `master`.
- `https://www.threetwoa.live` returns HTTPS 200 through EdgeOne; immutable `/_astro/*` assets return `eo-cache-status: HIT`.
- A real `https://img.threetwoa.live/...` object returns 200 through Cloudflare R2 with `cf-cache-status: HIT`.
- The domain is not ICP-filed, so this release does not claim mainland EdgeOne node acceleration.
- A Windows-local Vercel adapter build may end with a symlink `EPERM` after generating the site. Cloud production and the EdgeOne build path remain the release gates.

## 中文说明

**v1.3.0** 接在 `v1.2.0` 之后，重心是多平台交付、Ask / LiveChat，以及移动端与性能 V3。

主入口：https://www.threetwoa.live

Vercel 备用：https://fork-firefly.vercel.app

### 本版重点

**生产交付**

- 对外链路统一为 `www.threetwoa.live` → EdgeOne CDN → Vercel 源站。
- Cloudflare 负责权威 DNS，并用 `img.threetwoa.live` 的 R2 承接文章与评论大图。
- Vercel 与 EdgeOne 按 HTML、`/_astro/*`、Pagefind、普通 assets、`/api/*` 分层缓存。
- EdgeOne Pages adapter 继续保留做兼容回归，但当前生产不是 Pages 托管。

**Ask 与 LiveChat**

- 新增 HeroUI Pro React 问答岛，支持四种人设、站内检索、来源 Prompt 与流式回答。
- 点击桌宠可打开 LiveChat 浮窗，两端共用同一个服务端代理。
- 浏览器只请求同源 `/api/ask`，MaxKB token 不下发客户端。
- Ask 当前有意保持 DEV-only；生产页面、API 与浮窗默认关闭，等上云方案完成后再开放。

**性能与移动端**

- 延续 `v1.2.0` 的 Swup 生命周期、图片物化和加载策略治理。
- 移动端不再把 PC 等比缩小：RepelText 与 TagCloud 重装饰归零，Calendar / Recommend 不重复拉元数据，底部冗余侧栏不渲染，长条控制收成 icon。
- V3 趋势结果：移动 LCP `3241 → 2221 ms`（-31.5%）、移动 DOM `3597 → 3015`（-16.2%）、forced layout `3734 → 2590 ms`（-30.6%）、TagCloud reflow `723 → 140 ms`（-80.6%）、CLS `0`。
- LCP 是线上旧版与 localhost 当前版的趋势对比，不冒充同环境严格 A/B。

**内容与发文**

- 发布多批 Knowledge、Agentic Coding、求职面试与合集索引内容，并同步动态。
- 新增 AI Morning Brief、GitHub Weekly Hot 两条发文技能及其合集 / 词表登记。
- 扩展 CSDN 教程、小林 coding、鱼皮 VibeCoding 等内容集合。

**体验与修复**

- 收敛 Footer、侧栏平衡、标签墙、时间线、动态评论、桌宠移动与赞助交互。
- Footer 改回独立竹月绿色系，浇灌小草不再跟随全站 `--hue`（黑紫草已修）。
- 合集卡加统一宣纸安全层，浅底/高频封面不再和文字糊在一起。
- 日历封面换成 3 张 3D 像素角色短循环，旧风景 GIF 退出活跃池。
- 评论图接入 Cloudflare R2，并补齐取消 / 删除时清对象；COS 兼容链保留。
- 加固 Ask token、安全代理、API 禁缓存、动态行内评论与框架兼容。
- 隐藏示例内容，并同步更新 LQIP 元数据。

### 升级

没有有意引入 breaking change。继续使用 Node.js ≥ 22、pnpm 9：

```bash
pnpm install
pnpm check
pnpm type-check

```

评论大图按 `.env.example` 配置服务端 `R2_*`；`COS_*` 仍可回退。Ask 需要 `MAXKB_ACCESS_TOKEN`，并且必须先完成生产启用决策。

### 验收与边界

- Vercel Production 已 Ready，并跟随 `master`。
- `https://www.threetwoa.live` 经 EdgeOne 返回 HTTPS 200；immutable `/_astro/*` 命中 `eo-cache-status: HIT`。
- `https://img.threetwoa.live/...` 实际对象经 Cloudflare R2 返回 200 与 `cf-cache-status: HIT`。
- 域名未 ICP 备案，本版不宣称 EdgeOne 中国大陆节点加速完成。
- Windows 本地 Vercel adapter 可能在站点生成后因 symlink `EPERM` 收尾失败；云端 Production 与 EdgeOne 构建链才是发布门禁。
